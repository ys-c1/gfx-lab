# gfx-lab

五个小模块，面向 2D 渲染与音频，每个模块独立可构建、自带测试与演示产物。

| 模块 | 语言 | 产物 | 内容 |
|---|---|---|---|
| raster | C11 | demo.ppm | 三角形光栅化与 z 缓冲 |
| mip | C11 | demo.ppm | 盒式金字塔与纹理采样 |
| atlas | C11 | demo.txt | 序列图集货架打包 |
| mixer | C11 | demo.wav、demo_pan_*.wav | 总线混音与增益、等功率声像 |
| cull | C11 | demo.txt | 视口剔除与排序 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## mixer：等功率声像（`mixer/src/pan.{h,c}`）

旧的线性声像在中间对左右各给 0.5，总功率只有 0.5（−3.01 dB），听感发空。
现在拆成两段：

1. **按声像律算左右增益** `mx_pan_gains()`：等功率律取
   `theta = (p+1)·π/4`、`gL = cos θ`、`gR = sin θ`，恒有 `gL² + gR² = 1`；
   线性律 `gL = (1−p)/2`、`gR = (1+p)/2` 保留作对照。`p ∈ [−1, +1]`
   （−1 硬左、0 居中、+1 硬右）。逆运算 `mx_pan_position()` 由增益反解位置。
2. **按增益分配到通道** `mx_pan_spread()`：总线按 L/R 对解释，
   第 k 对 `(2k, 2k+1)` 的左声道乘 `gL`、右声道乘 `gR`；2 声道一对、
   8 声道四对。`mx_pan_apply()` 是两段的合并封装。

**不开启时与现在一模一样**：`enabled == 0` 在参数校验和任何写入之前直接返回，
总线逐位不变；旧的 `mx_add()`/`demo.c` 路径未改动，`demo.wav` 逐字节不变
（`sha256 837d4260…`，`make -C mixer pan-demo` 也会用 `memcmp` 复验旁路）。

**非法组合一次列全**：`mx_pan_validate()` / `mx_pan_apply()` 把所有冲突写进
`MxPanErr`（`item[]` 逐项、`msg` 用 `"; "` 连接），拒绝发生在写缓冲之前。
检查项：`enabled ∉ {0,1}`、`law` 未知、`position` 非有限或越出 `[−1,+1]`、
总线缓冲为空、声道数不是 `[2, 8]` 内的偶数、`frames < 0` 或 `frames > cap`。

**指标（`make -C mixer pan-bench`，另跑 `python3 -I pan/verify/handcalc.py` 复算）**：
2 与 8 声道各 21 个位置，逐项对照本文件内独立算出的 double 解析解。

| 声像律 | 声道 | L/R 对 | 增益误差(最大) | 能量误差 | 声像位置误差 | 逐样本误差(最大/rms) | 耗时(中位) |
|---|---|---|---|---|---|---|---|
| linear | 2 | 1 | 3.5e-08 | 6.6e-08 | 4.8e-08 | 2.5e-08 / 6.9e-09 | 2.23 µs (0.272 ns/样本) |
| linear | 8 | 4 | 4.1e-08 | 6.6e-08 | 4.8e-08 | 4.2e-08 / 7.3e-09 | 3.98 µs (0.122 ns/样本) |
| equal-power | 2 | 1 | 4.4e-08 | 8.8e-08 | 4.8e-08 | 2.7e-08 / 1.1e-08 | 2.23 µs (0.272 ns/样本) |
| equal-power | 8 | 4 | 7.9e-08 | 8.8e-08 | 4.8e-08 | 4.6e-08 / 1.2e-08 | 3.99 µs (0.122 ns/样本) |

耗时是 4096 帧总线、201 次取中位的单次 `mx_pan_apply`（内层连跑 64 遍/次，
含每次从快照恢复）；2 声道受 `clock_gettime` 粒度限制，8 声道样本更多、
单样本耗时约为其一半。

**两种律的差异（另列，同一请求位置，`build/pan_diff.csv`）**：端点 `p = ±1`
两律完全一致；中间偏离最大，`p = 0` 时左右增益各差 +0.2071、能量 0.5 → 1.0、
电平 +3.0103 dB —— 这正是“中间发空”的来源。把等功率增益按线性律反解，
读回的位置最多偏 0.0905（在 `p = ±0.6` 附近），端点仍重合。

  位置反解、2/4/8 声道分配、非法组合逐项列举且零写入）
- 演示：`make -C mixer pan-demo`（`demo_pan_*.wav`）
- 基准：`make -C mixer pan-bench`（2/8 声道 × 两律；导出 CSV 并跑 Python 复算）
