# gfx-lab

小模块集合，面向 2D 渲染与音频，每个模块独立可构建、自带测试与演示产物。

| 模块 | 语言 | 产物 | 内容 |
|---|---|---|---|
| raster | C11 | demo.ppm | 三角形光栅化与 z 缓冲 |
| mip | C11 | demo.ppm | 盒式金字塔与纹理采样 |
| atlas | C11 | demo.txt | 序列图集货架打包 |
| mixer | C11 | demo.wav | 总线混音与增益 |
| cull | C11 | demo.txt | 视口剔除与排序 |
| shadow | C11 | demo.pgm | 点光源遮挡与阴影图 |
| asset | C11 | demo.gpak | 资源打包与解包 |
| occ | C11 | demo.pgm / demo_*_diff.txt | 遮挡段逐段覆盖率与掩码汇总 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## occ：遮挡段覆盖与汇总

两段式，可独立开关：

1. `occ_compute` 逐段光栅化（Amanatides-Woo），每段输出独立掩码平面、覆盖格数与覆盖率；
2. `occ_aggregate` 把各段平面 OR 合并成一张总掩码，并记录每段新并入的格子（`added[]`）。
   不调用汇总时，阶段一的掩码与覆盖率保持不变（测试中有字节级比对）。

覆盖语义：线段与格子有正长度相交才算覆盖；精确穿过网格角点时走对角步，角点相切的两个格子不计；
落在网格线上的线段同时覆盖相邻两排。独立参考实现 `occ_reference_mask` 用 Liang-Barsky 逐格裁剪，
与光栅器逐字节对照。错误均经 `bad_seg` 指明段号：零段数、端点越界、空掩码、汇总掩码为空。
演示在 256×256 与 1024×1024 两档输出覆盖率误差、汇总次数、耗时，并写出可按段号追溯的汇总前后差异清单。
