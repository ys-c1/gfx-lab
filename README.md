# gfx-lab

五个小模块，面向 2D 渲染与音频，每个模块独立可构建、自带测试与演示产物。

| 模块 | 语言 | 产物 | 内容 |
|---|---|---|---|
| raster | C11 | demo.ppm | 三角形光栅化与 z 缓冲 |
| mip | C11 | demo.ppm | 盒式金字塔与纹理采样 |
| atlas | C11 | demo.txt | 序列图集货架打包 |
| mixer | C11 | demo.wav | 总线混音与增益 |
| cull | C11 | demo.txt | 视口剔除与排序（含增量视口更新） |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## cull 增量视口更新

视口只轻微移动时，全量重算每帧都要扫全部 N 个对象。`cull_inc` 改为两段式：

1. `cull_diff`：比较前后视口，分解出进入带（新视口−旧视口）与退出带（旧视口−新视口）两个差异矩形；
2. `cull_inc_update`：借助均匀网格空间索引，只收集差异带内的候选对象并判定进出，维护升序可见集合；每帧经 `CullIncStats` 报告候选数、进入/退出数与更新对象总数。

无差异时零候选、零更新，可见集合保持不变。空视口（w/h 为 0）或负尺寸返回负值错误码，`err` 字符串指出具体字段（如 `new_view.w = -5 (negative size)`）。

- 测试：`make -C cull test-inc`（981 项，含与全量 `cull_run` 的逐项相等校验、无差异集合不变、错误字段、差异几何、随机压力）
- 基准：`make -C cull bench`（1 万 / 10 万对象，对照全量重算，报告更新数、候选数、误差与耗时；增量结果与全量逐项相等，误差为 0）
