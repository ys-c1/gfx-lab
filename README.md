# gfx-lab

五个小模块，面向 2D 渲染与音频，每个模块独立可构建、自带测试与演示产物。

| 模块 | 语言 | 产物 | 内容 |
|---|---|---|---|
| raster | C11 | demo.ppm | 三角形光栅化与 z 缓冲 |
| mip | C11 | demo.ppm | 盒式金字塔与纹理采样 |
| atlas | C11 | demo.txt | 序列图集货架打包 |
| mixer | C11 | demo.wav | 总线混音与增益 |
| cull | C11 | demo.txt | 视口剔除与排序 |
| shadow | C11 | demo.pgm / demo_soft.pgm | 线段光源阴影图 / 曲线权重半影 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## shadow：曲线权重半影（`shadow/src/penumbra.{h,c}`）

原来半影只是一条固定宽度的线性斜坡，边缘像一张贴纸贴在画面上。现在拆成两段：

1. **按距离算曲线权重** `sh_pen_weights`：逐像素量到硬阴影边界的距离 `d`，
   除以该点由光源半径与遮挡体距离推得的半影半宽 `h`，得到归一化坐标
   `x = d/h ∈ [-1,1]`（受光侧为正），再查曲线表得到权重 `w`。
   单像素入口 `sh_pen_weight_pixel` / `sh_pen_edge_coord` 可单独取到 `x` 与 `w`。
2. **按权重混合明暗** `sh_pen_blend`：`out = dark + (light - dark) · w`，
   其中 `light` 是硬渲染器原本的距离衰减值、`dark = 0`，因此两段管线与
   `sh_render` 的几何完全一致，只把二值遮挡换成曲线混合。

**关闭时逐字节相同**：`sh_render_pen(..., cfg == NULL)` 或 `cfg->enable == 0`
直接转发到未改动的 `sh_render()`，内存与写出的 PGM 都逐字节一致（测试用
`memcmp` 和逐字节 `fgetc` 双重校验）。

**类型不符要拒绝，并指出字段名**：配置是强类型的。`sh_pen_field_type()`
给出每个字段的类型，`sh_pen_cfg_set()` 要求调用方声明值类型；类型不符返回
`SH_PEN_ERR_TYPE` 并在 `err->field` 写出字段名（`enable`、`src_radius`、
`width_scale`、`curve`、`curve_exp`、`curve_levels`）。未知字段、越界值、
空指针分别返回 `SH_PEN_ERR_FIELD` / `SH_PEN_ERR_RANGE` / `SH_PEN_ERR_NULL`，
同样带字段名。

**曲线档位与曲线表**：`curve_levels` 是 LUT 档位数（2…4096），曲线预设
`linear` / `smooth` / `disk` / `pow`。`sh_pen_curve_table()` 取回整张表，
`sh_pen_curve_export()` 导出 TSV；管线正是按这张表（线性插值）求值，所以
导出的表能逐像素复现权重。`disk` 是圆盘光源被直边遮挡时的解析可见比例，
`pow` 的指数由 `curve_exp` 给出。

**误差与内存（`make -C shadow pen-bench`，对照逐像素 512 采样圆盘参考）**：

| 分辨率 | 曲线 | 全图 rms | 半影带 rms | 半影宽度（实测/解析/误差） | 曲线档位 | 半影像素 | 峰值内存 |
|---|---|---|---|---|---|---|---|
| 256 | linear | 0.0087 | 0.098；硬边 0.278 | 4.57 / 4.53 / 0.03 px | 256 | 1091 | 263 KB |
| 256 | smooth | 0.0057 | 0.060；硬边 0.278 | 3.63 / 3.45 / 0.19 px | 256 | 1091 | 263 KB |
| 256 | disk | 0.0067 | 0.071；硬边 0.278 | 4.04 / 3.89 / 0.15 px | 256 | 1091 | 263 KB |
| 256 | pow | 0.0155 | 0.229；硬边 0.278 | 3.86 / 3.58 / 0.28 px | 256 | 1091 | 263 KB |
| 1024 | linear | 0.0088 | 0.098；硬边 0.277 | 18.32 / 18.18 / 0.14 px | 256 | 17980 | 4.0 MB |
| 1024 | smooth | 0.0058 | 0.062；硬边 0.277 | 13.94 / 13.83 / 0.11 px | 256 | 17979 | 4.0 MB |
| 1024 | disk | 0.0068 | 0.072；硬边 0.277 | 15.75 / 15.62 / 0.13 px | 256 | 17980 | 4.0 MB |
| 1024 | pow | 0.0155 | 0.229；硬边 0.277 | 14.52 / 14.39 / 0.13 px | 256 | 17980 | 4.0 MB |

半影带误差只在参考版既非全亮也非全暗的像素上统计，且按覆盖率（去除距离衰减）
归一；同列括号里是旧硬边的同一指标，可见曲线权重把误差降到硬边的四分之一左右。
`lv=1024` 的误差与宽度和 `lv=256` 一致（曲线本身才是精度瓶颈），档位主要影响
内存：同为 1024² 图，`lv=256` 峰值 4,195,328 B、`lv=1024` 峰值 4,198,400 B，
只多 3 KB 的表；而 256²→1024²（同为 `lv=256`）峰值从 263,168 B 增到
4,195,328 B，即每像素 4 B 的权重缓冲。基准同时导出
`build/curve_<preset>_<levels>.tsv`。
