# gfx-lab

五个小模块，面向 2D 渲染与音频，每个模块独立可构建、自带测试与演示产物。

| 模块 | 语言 | 产物 | 内容 |
|---|---|---|---|
| raster | C11 | demo.ppm | 三角形光栅化与 z 缓冲 |
| mip | C11 | demo.ppm | 盒式金字塔与纹理采样 |
| atlas | C11 | demo.txt | 序列图集货架打包 |
| mixer | C11 | demo.wav | 总线混音与增益 |
| cull | C11 | demo.txt | 视口剔除 + 两阶段遮挡剔除（深度图） |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## cull 的遮挡剔除

分两段：

1. `cull_depth_render` 把遮挡矩形栅格化进分辨率可配的深度图（`cull_depth_init(w,h,...)`），每格记录最近的深度。只有**整格被遮挡者覆盖**时才写入深度，格内不完整覆盖的一律留空。
2. `cull_occlusion` 对候选逐个做深度测试：候选覆盖到的每一格都必须有严格更近的遮挡者，才剔除；否则保留。因此深度图离散化只会**少剔**，不会**误剔**。

`enabled == 0` 时不做遮挡测试，可见集合与输入一一对应（升序，`culled == 0`），也不需要深度图。`enabled == 1` 且深度图为空（NULL、未渲染或无任何格被覆盖）返回 `CULL_ERR_EMPTY_DEPTH`。坐标或深度非有限返回 `CULL_ERR_NONFINITE`，并用 `err_index` 指出是第几个对象（0 起）；负宽高返回 `CULL_ERR_RECT`，同样带序号。

`demo` 打印：12 个逐个手算的小场景、1k/1w 候选在 64/256/1024 分辨率下的剔除数、误剔除数（与手算及精确参考逐对象对照）、漏剔数、两段耗时，以及非整数坐标场景随分辨率收敛的过程。
