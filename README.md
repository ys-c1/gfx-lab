# gfx-lab

五个小模块，面向 2D 渲染与音频，每个模块独立可构建、自带测试与演示产物。

| 模块 | 语言 | 产物 | 内容 |
|---|---|---|---|
| raster | C11 | demo.ppm | 三角形光栅化与 z 缓冲 |
| mip | C11 | demo.ppm | 盒式金字塔与纹理采样 |
| atlas | C11 | demo.txt | 序列图集货架打包 |
| atlasmip | C11 | demo.idx | 块感知图集金字塔：贴边扩展、逐块层链、按块裁剪取样与渗色度 |
| mixer | C11 | demo.wav | 总线混音与增益 |
| cull | C11 | demo.txt | 视口剔除与排序 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## atlasmip 三段管线

相邻块的颜色在普通整图金字塔里会沿降采样层级互相渗入。`atlasmip` 分三段处理：

1. **贴边扩展**：块外像素按块边界 clamp-to-edge 填充（`am_build` 的 `extend` 开关）；`extend=0` 时基底与输入逐字节一致。
2. **逐块层链**：每块独立建盒式金字塔，2×2 降采样的索引只在本块内钳制，邻块数据永不参与。
3. **按块裁剪取样**：UV 钳制到目标块当前层级的像素矩形，越界只取块边，读不到邻居。

渗色度以一条朴素整图链为对照：朴素像素的 footprint 中心映射回基底定块，与该块自己的同层链值逐通道比较，报渗色像素数、误差和与最大误差。块边界（含整图尺寸）写入 `AmIndex` 并可序列化（magic `AMID`）。`levels<=0` 返回 `-2`，块越界返回 `-3` 并经 `bad_block` 指出序号。`ref/verify.py` 是独立的纯 Python 暴力参照，与 C 侧手推值交叉核对。
