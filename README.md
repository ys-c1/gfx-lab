# gfx-lab

小模块集合，面向 2D 渲染与音频，每个模块独立可构建、自带测试与演示产物。

| 模块 | 语言 | 产物 | 内容 |
|---|---|---|---|
| raster | C11 | demo.ppm | 三角形光栅化与 z 缓冲 |
| mip | C11 | demo.ppm | 盒式金字塔与纹理采样 |
| atlas | C11 | demo.txt | 序列图集货架打包 |
| mixer | C11 | demo.wav | 总线混音与增益 |
| cull | C11 | demo.txt | 视口剔除与排序 |
| sweep | C11 | demo.txt + active_*.csv | 扫描线活动收集 + 入出事件遮挡排序 |

每个模块：`make -C <模块> test`，演示：`make -C <模块> demo`。

## sweep：两层遮挡排序

解决"对象深度每帧抖动导致遮挡次序来回跳"的问题，分两层：

1. **扫描线层**：每个对象的区间 `[x0,x1]` 拆成 ENTER/EXIT 两个事件，排序后推进扫描线，只收集覆盖当前位置的活动对象；同坐标 EXIT 先于 ENTER。
2. **事件序层**：ENTER 时按 `(深度, id)` 稳定插入活动表并持有该深度，EXIT 时摘除。共同存活对象的相对次序因此永不翻转——跳变量恒为 0。

对照的非扫描线模式不建事件、集合恒为全集、每个检查点按实时深度整表重排。

指标口径（见 `sweep/src/sweep.h` 的 `SweepStats`）：

- `events` 事件数（扫描线 2n，非扫描线 0）、`compares` 深度比较候选数、`pair_candidates` 重叠候选对；
- `jumps` 跳变量：相邻检查点共同存活对象对的相对序翻转数；
- `errors` 误差：持有序相对本检查点实时深度序的逆序对（稳定持有的偏差代价）；
- `algo_ns`/`elapsed_ns` 算法净耗时与含误差度量的总耗时。

错误约定：扫描线为空返回 `SWEEP_ERR_EMPTY`；区间倒置（含 NaN）返回 `SWEEP_ERR_INVERTED` 并经 `bad_index` 指出对象序号。测试含 5 对象逐检查点手算对照、独立事件重放交叉验证与抖动稳定性核对；演示跑 1000 / 10000 两档并导出 1000 档活动表 CSV。
