# shadow

2D 阴影图：点光源照射若干线段遮挡物，逐像素计算"是否被遮挡"与距离衰减。

## 原始接口

```c
int sh_render(ShadowMap *m, const ShLight *light, const ShSeg *segs, int nseg);
```

整幅重绘，行为与引入动画接口之前完全一致。

## 动画接口

一帧分两步：

1. `sh_lerp_light()` 在前后两个关键帧光源之间插值；
2. 只更新"可能变化"的块。

```c
int sh_anim_step(ShAnim *a, const ShLight *prev, const ShLight *next, float t,
                 int frame_span, int interpolate, ShStepStats *stats, ShError *err);
```

- `t`：插值系数，必须有限且落在 `[0,1]`。
- `frame_span`：两关键帧间隔的帧数，必须 `> 0`。
- `interpolate == 0`：忽略 `t` 与 `frame_span`，直接使用 `next` 做整幅 `sh_render`，
  与旧行为逐位相同（基准中每帧验证）。
- 出错返回非零码，`ShError.param` 指明出问题的参数名（`"t"`、`"frame_span"`、
  `"prev"`、`"next"` …），`ShError.msg` 给出带具体数值的原因。失败的调用不推进帧。

轨迹导出：`sh_write_trajectory(path, prev, next, frames, frame_span, err)` 写
`frame,t,x,y,radius,intensity` 的 CSV。

## 增量更新做了什么

缓存两张表：每像素可见性掩码 `occ`，以及每块误差上界 `err_bound`。每个块走三条路径之一：

| 路径 | 条件 | 代价 |
|---|---|---|
| 重算（recomputed） | 光源运动可能把块内某像素扫过遮挡物端点 | 全段测试 + 着色 |
| 重着色（re-shaded） | 可见性不可能变，但衰减值超出容差 `eps` | 每像素一次距离计算 |
| 跳过（untouched） | 可见性不变且衰减界仍在 `eps` 内 | 无 |

"可见性可能变"的判定是精确几何：像素 P 的遮挡状态只会在 `t`（L→P 参数）、`u`（沿遮挡物参数）
越过边界时翻转。`u` 的边界对应"P 位于从光源经遮挡物端点 E 的延长线上"，即端点 E 背后、
以 E-L0 与 E-L1 为界的楔形区域。该楔形被光栅化，命中的块才重算。光源路径穿过遮挡物、
或楔形过宽（视角超过约 80°）、或光源靠近端点时，退回整幅刷新。

容差默认 `eps = 1/255`（一个 8 位灰度级），可用 `sh_anim_set_eps()` 调整。

## 测试

`make -C shadow test`：

- 旧接口行为回归；
- 插值的边界与位精确性（`t=0/1` 原样返回关键帧）；
- `t` 越界、`frame_span <= 0`、空指针、非法光源——逐一检查返回码与 `param` 名字；
- 关插值时与 `sh_render` 逐位相同；
- 增量结果与逐帧全量对照（误差 ≤ eps）；
- **掩码精确性**：每种场景每一步之后，缓存的可见性掩码都必须与全量重测完全一致
  （场景 / 256 块 / 512 图 / 光源穿越遮挡物 / 穿越端点 / 亚像素运动 / 密集场景 / 空场景）。

## 基准

`make -C shadow bench`，96 帧，插值开启，eps = 1/255，对照每帧 `sh_render` 全量重算。
坐标随分辨率缩放，两档跑同一场景。

### 慢速（亚像素运动）

```
+-------+-------+------------+------------+------------+---------+---------+
| size  | block | recomputed | re-shaded  | untouched  | inc ms  | full ms |

|   128 |     8 |  35.3%     |  50.2%     |  14.6%     |    0.05 |    0.09 |
|   512 |    16 |  19.5%     |  59.5%     |  21.0%     |    0.53 |    1.36 |
+-------+-------+------------+------------+------------+---------+---------+

+-------+-------+---------+------------+---------------+---------+---------+---------+
| size  | block | speedup | recomputed | rec. px       | max err | rmse    |
+-------+-------+---------+------------+---------------+---------+---------+---------+
|   128 |     8 |  1.66x  |  90.4/256   |  5783/16384   | 0.001117| 0.000163|
|   512 |    16 |  2.57x  | 200.2/1024  | 51248/262144  | 0.001121| 0.000196|
+-------+-------+---------+------------+---------------+---------+---------+---------+
```

### 快速（约 2 像素/帧）

```
+-------+-------+------------+------------+------------+---------+---------+
| size  | block | recomputed | re-shaded  | untouched  | inc ms  | full ms |
+-------+-------+------------+------------+------------+---------+---------+
|   128 |     8 |  34.3%     |  65.7%     |   0.0%     |    0.06 |    0.09 |
|   512 |    16 |  20.6%     |  79.4%     |   0.0%     |    0.58 |    1.38 |
+-------+-------+------------+------------+------------+---------+---------+

+-------+-------+---------+------------+---------------+---------+---------+---------+
| size  | block | speedup | recomputed | rec. px       | max err | rmse    |
+-------+-------+---------+------------+---------------+---------+---------+---------+
|   128 |     8 |  1.60x  |  87.8/256   |  5616/16384   | 0       | 0       |
|   512 |    16 |  2.38x  | 211.3/1024  | 54093/262144  | 0       | 0       |
+-------+-------+---------+------------+---------------+---------+---------+---------+
```

误差为与逐帧全量的最大逐像素绝对差；两档都 ≤ 一个灰度级。快速档运动更大，但块内像素整体
被重算，所以误差为 0；慢速档靠"重着色 + 跳过"，误差在容差内。

### 稳定性

```
repeat 128 run: final map identical
768-frame run: max err 0.003598, mean 0.000248 (bounded)
interpolation off vs legacy sh_render: bit-identical
```

- 同一输入重复运行，最终图逐位相同；
- 帧数放大 8 倍，误差不累积（每块误差界在跳过路径上累加，超过 eps 就重着色/重算）；
- 关插值时与旧 `sh_render` 逐位相同。

## 说明与限制

- 误差界是保守的：可见性判定精确（测试逐像素核对），但衰减界按块给出，因此部分块会
  被保守地重着色。块越小越精细，但每块固定开销越大；128 用 8、512 用 16。
- 光源路径若穿过遮挡物、或从端点附近经过、或扫过超过约 80°，会退回整幅刷新——正确性优先。
- 直接落在遮挡物直线上的像素在旧的逐像素实现里本身就处于浮点刀锋（`t=1` 的符号随光源
  位置抖动）。这些像素所在块在增量路径中始终重算，结果与全量一致，但"是否被遮挡"本身
  由浮点误差决定。
